Let's get you in the game

Takes about two minutes. You'll install one free app, scan a code I send you, and flip a switch before you play.

  1. Install WireGuard

    It's the free, official app. Don't use any other VPN app for this.

    Get it on Android Get it on iPhone

  2. Message me for your code

    I'll send you a personal QR code on WhatsApp or Discord. It's yours only, so please don't share it.

  3. Scan the code

    In WireGuard, tap +, then Scan from QR code. Give it any name and allow the VPN permission when asked.

  4. Switch it on, then open the game

    Turn the toggle on before launching. Turn it off when you're done playing so your normal apps use your regular connection.

Heads up: some games flag VPN connections. Use it at your own risk, and if the game warns you about VPNs, stop and tell me.
Not connecting? Turn the toggle off and on again, then message me.
